# Messages in LLM — Interview Notes

## 1. What is a Message in LLM?

In Large Language Models (LLMs), a **message** is a single piece of communication between the user and the AI.

A message generally contains:

- **Role** → Who sent the message?
- **Content** → What does the message say?
- **Metadata** → Additional information about the message.

### Common Roles

- `SystemMessage` → Gives instructions to the LLM.
- `HumanMessage` → Represents user input.
- `AIMessage` → Represents the AI's response.
- `ToolMessage` → Represents the result returned by a tool.

---

# 2. Basic LLM with Text Prompt

The simplest way to interact with an LLM is by passing a string.

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

model = ChatOpenAI(
    model="gpt-4o-mini"
)

response = model.invoke("Please tell me what is AI")

print(response.content)
````

 ### What does it do?

 Here:

```
model.invoke("Please tell me what is AI")
```

 The string is treated as a **Human/User input**.

 The model generates an **AI response**.

 ### Flow

```
User String
     ↓
    LLM
     ↓
AI Response
```

---

 # 3\. Text Prompt

 A **text prompt** is simply a string given to the LLM.

 Example:

```
response = model.invoke("What is LangChain?")

print(response.content)
```

 ### What does it do?

 It sends one simple instruction/question to the LLM.

 ### Important

 A simple text prompt does not automatically represent a conversation history.

 For example:

```
model.invoke("What is LangChain?")
```

 and later:

```
model.invoke("What are its advantages?")
```

 The second call does not automatically know what was asked in the first call.

 If you want conversation history, you need to provide previous messages.

---

 # 4\. Message-Based Prompt

 Instead of passing a simple string, we can pass a **list of message objects**.

 Example:

```
from langchain.messages import SystemMessage, HumanMessage

messages = [
    SystemMessage(content="You are a poetry expert."),
    HumanMessage(content="Write a poem about nature.")
]

response = model.invoke(messages)

print(response.content)
```

 ### What does it do?

 We explicitly tell the LLM:

 1. Who the assistant should behave as.
2. What the user wants.

 ### Flow

```
SystemMessage
      ↓
HumanMessage
      ↓
     LLM
      ↓
 AI Response
```

 # 5\. Types of Messages

 LangChain commonly uses these message types:

```
SystemMessage
HumanMessage
AIMessage
ToolMessage
```

---

 # 6\. SystemMessage

 ## Definition

 `SystemMessage` contains instructions that tell the LLM **how it should behave**.

 Example:

```
from langchain.messages import SystemMessage

system_msg = SystemMessage(
    content="You are a helpful Python teacher."
)
```

 ### What does it do?

 It gives the LLM a role or behavior.

 For example:

```
You are a Python expert.
Explain concepts simply.
Always provide examples.
```

 The LLM follows these instructions while generating the response.

 ### Example

```
messages = [
    SystemMessage(
        content="You are a Python expert."
    ),
    HumanMessage(
        content="What is a list in Python?"
    )
]

response = model.invoke(messages)

print(response.content)
```

---

 # 7\. HumanMessage

 ## Definition

 `HumanMessage` represents **input from the user**.

 Example:

```
from langchain.messages import HumanMessage

human_msg = HumanMessage(
    content="What is LangChain?"
)
```

 ### What does it do?

 It tells the LLM what the user is asking or requesting.

 Example:

```
messages = [
    HumanMessage(
        content="Explain artificial intelligence."
    )
]

response = model.invoke(messages)

print(response.content)
```

---

 # 8\. AIMessage

 ## Definition

 `AIMessage` represents a **response generated by the AI/LLM**.

 Example:

```
from langchain.messages import AIMessage

ai_msg = AIMessage(
    content="AI stands for Artificial Intelligence."
)
```

 Normally, you don't manually create `AIMessage` for a normal response.

 The LLM creates an `AIMessage` as its response.

 Example:

```
response = model.invoke(
    "What is AI?"
)

print(type(response))
print(response.content)
```

 The response is an AI message.

 ### AIMessage can contain

 - Text content
- Tool calls
- Metadata
- Additional response information

---

 # 9\. ToolMessage

 ## Definition

 `ToolMessage` represents the **result/output returned by a tool**.

 It is mainly used when an LLM calls an external tool.

 Example flow:

```
User
 ↓
HumanMessage
 ↓
LLM
 ↓
AIMessage
 ↓
Tool Call
 ↓
Tool
 ↓
ToolMessage
 ↓
LLM
 ↓
Final AIMessage
```

 ### Example

 Suppose we have a weather tool:

```
from langchain.tools import tool

@tool
def get_weather(city: str) -> str:
    """Get weather for a city."""
    return f"The weather in {city} is sunny."
```

 The LLM may decide to call:

```
get_weather("Delhi")
```

 The tool returns:

```
The weather in Delhi is sunny.
```

 That tool result is represented as a `ToolMessage` in the tool-calling workflow.

---

 # 10\. Message Metadata

 Messages can also contain additional information called **metadata**.

 Example:

```
from langchain.messages import HumanMessage

human_msg = HumanMessage(
    content="Hello!",
    name="vivek",
    id="msg_123"
)
```

 Here:

```
content → "Hello!"
name    → "vivek"
id      → "msg_123"
```

 ### What does it do?

 #### `content`

 Contains the actual message.

```
content="Hello!"
```

 #### `name`

 Can identify the sender or user.

```
name="vivek"
```

 #### `id`

 Can be used as a unique identifier for the message.

```
id="msg_123"
```

 Message IDs can be useful for tracking, debugging, or tracing messages.

 # 11\. Complete Message Example

```
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain.messages import (
    SystemMessage,
    HumanMessage
)

load_dotenv()

model = ChatOpenAI(
    model="gpt-4o-mini"
)

messages = [
    SystemMessage(
        content="You are a helpful Python teacher."
    ),
    HumanMessage(
        content="Explain Python lists."
    )
]

response = model.invoke(messages)

print(response.content)
```

 ### What happens here?

```
SystemMessage
"You are a helpful Python teacher."
          ↓
HumanMessage
"Explain Python lists."
          ↓
        LLM
          ↓
      AIMessage
          ↓
    response.content
```

 # 12\. Conversation History

 One major advantage of messages is that we can maintain conversation history.

 Example:

```
messages = [
    SystemMessage(
        content="You are a helpful assistant."
    ),

    HumanMessage(
        content="What is LangChain?"
    ),

    AIMessage(
        content="LangChain is a framework for building LLM applications."
    ),

    HumanMessage(
        content="What can we build with it?"
    )
]

response = model.invoke(messages)

print(response.content)
```

 The LLM can use the previous messages as context.

 ### Important

 A list of messages can represent the conversation history:

```
SystemMessage
      ↓
HumanMessage
      ↓
AIMessage
      ↓
HumanMessage
      ↓
AIMessage
```

 # 13\. Text Prompt vs Message Prompt

 | Text Prompt | Message Prompt |
| --- | --- |
| Simple string | List of message objects |
| Easy for simple questions | Better for conversations |
| Less control over roles | Explicit roles |
| No structured message history | Can maintain conversation history |
| Good for simple tasks | Good for complex LLM applications |

### Text Prompt

```
model.invoke(
    "What is LangChain?"
)
```

 ### Message Prompt

```
messages = [
    SystemMessage(
        content="You are a helpful teacher."
    ),
    HumanMessage(
        content="What is LangChain?"
    )
]

model.invoke(messages)
```

 # 16\. Interview Questions

 ## Q1. What is a Message in LangChain?

 **Answer:**

 A Message is a structured piece of communication between the user, AI, system, or tool. It contains information such as role, content, and metadata.

---

 ## Q2. What is SystemMessage?

 **Answer:**

 `SystemMessage` provides instructions that define how the LLM should behave.

---

 ## Q3. What is HumanMessage?

 **Answer:**

 `HumanMessage` represents the user's input or request.

---

 ## Q4. What is AIMessage?

 **Answer:**

 `AIMessage` represents the response generated by the LLM. It can contain text, tool calls, and metadata.

---

 ## Q5. What is ToolMessage?

 **Answer:**

 `ToolMessage` represents the result returned by a tool after the LLM requests a tool call.

---

 ## Q6. Why use messages instead of a simple string?

 **Answer:**

 Messages provide structure and allow us to define different roles such as system, user, AI, and tool. They are especially useful for maintaining conversation history and building complex LLM applications.

---

 ## Q7. What is the difference between Text Prompt and Message Prompt?

 **Answer:**

 A text prompt is a simple string passed to the LLM. A message prompt uses structured message objects such as `SystemMessage`, `HumanMessage`, `AIMessage`, and `ToolMessage`.
